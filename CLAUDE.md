# CLAUDE.md

## Scope of changes

- Only make edits within the `Scripts` folder(s), or to script-like files (`.cs`, `.html`, `.jslib`).
- Scene and prefab files (`.unity`, `.prefab`, and other Unity editor assets) may be **read** for context, but must **never** be modified.
- Any changes to scenes, prefabs, or other editor assets are made by the user only — do not edit them yourself, even if asked to fix something that lives there. Point out what needs to change and let the user make the edit in the Unity Editor.
